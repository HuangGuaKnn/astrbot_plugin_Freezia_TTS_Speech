# Freezia TTS Speech（astrbot_plugin_Freezia_TTS_Speech）

让角色在合适的时机开口说话。插件拦截 AstrBot 的 LLM 回复，按「发声档案」决定这条回复要不要念出来，
清洗掉不该念的内容（可选再交给 LLM 口语化或翻译成其他语言），再交给 AstrBot 里已经配置好的 TTS 服务
（Genie TTS、GSVI、OpenAI TTS 等）合成。角色也可以通过工具主动选择用语音说话。

本插件用来**完全替代 AstrBot 自带的 TTS 触发逻辑**，合成仍然使用 AstrBot 的 TTS 服务提供商。

## 安装前必做

1. **关闭 AstrBot 自带的语音回复**：AstrBot 配置 →「AI」分组 → 关闭「语音回复」（配置键 `provider_tts_settings.enable`）。
   不关的话，同一条回复会被自带 TTS 和本插件各合成一次。
2. **保留 TTS 服务提供商**：在「服务提供商」里添加好的 TTS 服务（例如 Genie TTS）不要删，本插件用它合成。
3. **关闭流式输出**：本插件在流式回复中不可用。流式回复会被跳过，并在日志中警告（10 分钟最多一次）。

WebUI 会检测上面这几项，没处理好时在页面顶部显示提醒。

## 要求

- AstrBot ≥ 4.24（需要插件页面功能）
- 至少一个 TTS 服务提供商
- 使用「角色主动用语音」时，对话模型需要支持函数调用；使用 LLM 清洗或翻译时，需要一个对话模型

## 安装

- 在 AstrBot 插件管理中填写仓库地址 `https://github.com/HuangGuaKnn/astrbot_plugin_Freezia_TTS_Speech` 安装；
- 或从 [Releases](https://github.com/HuangGuaKnn/astrbot_plugin_Freezia_TTS_Speech/releases) 下载附件 `astrbot_plugin_Freezia_TTS_Speech.zip`，在插件管理中上传安装。附件 `SHA256SUMS.txt` 提供校验值。

安装后重载插件，在控制台的插件页面打开「Freezia TTS Speech」完成设置。

## 工作流程

```
LLM 回复 → 判定是否发声 → 正则过滤 →（LLM 清洗 / 翻译）→ 发音词典 → 按语言选 TTS 服务 → 串行合成 → 发送
```

**判定顺序**（命中即停）：

1. 插件全局关闭 / 档案关闭 / 会话静音 / 档案为「仅文字」→ 不发声
2. 用户消息含「不出声短语」→ 不发声（先于强制出声判定，避免「别出声」命中「出声」）
3. 过滤后没有可读内容 → 不发声
4. 用户消息含「强制出声短语」→ 发声
5. 角色本轮调用了语音工具 → 发声
6. 用户发来的是语音消息（档案开启「收到语音时用语音回复」）→ 发声
7. 群聊 / 私聊不允许 → 不发声
8. 过滤后字数超过「被动触发上限」→ 不发声
9. 冷却中 → 不发声
10. 按概率决定；回复里有情绪符号（默认 `！`、`♡`、`哈哈` 等）时概率乘以情绪联动系数

第 4～6 步属于「强制出声」，不受群聊限制、字数上限、冷却和概率影响。

**发送方式**：

- 文字 + 语音：文字立即发出，语音（含清洗、翻译）在后台完成后补发，不会拖慢文字回复。
- 仅语音：等合成完成后把文字替换成语音；任何一步失败都照常发文字。
- 群聊里「仅语音」默认改为「文字 + 语音」（可在档案中关闭）。

任何清洗、翻译、合成或发送失败都只影响语音，文字回复照常发送，错误记入日志和 WebUI 的判定记录。

## 角色主动用语音

插件注册了 LLM 工具 `freezia_voice_reply(language)`。角色觉得这一轮适合用声音说时（情绪强烈、亲密或安慰的时刻、
用户想听声音、念诗唱歌）可以调用它，这一轮的回复就会被念出来；`language` 可以临时指定语音语言。

- 仍然受插件开关、档案开关、会话静音、「仅文字」和用户「别出声」约束，被拒绝时工具会把原因告诉角色。
- 同一会话两次主动语音之间有最短间隔（默认 60 秒），防止每句都调用。
- 调用工具的那一轮会多一次 LLM 往返；工具说明每次请求都会带上，已尽量写短。
- 可以在档案里关闭；也可以在 AstrBot 的工具管理里停用 `freezia_voice_reply`。

## 语音翻译（文字发原文，语音念外语）

AstrBot 的 TTS 服务把语言写在各自的配置里（如 Genie 的 `genie_language`、GSVI 的 `text_lang`），合成时不能临时改语言。所以：

1. 在 AstrBot 里为每种语言单独建一个 TTS 服务条目（例如同一音色的「日语」条目）；
2. 在 WebUI「会话与全局 → 语言与翻译」里把语言代码（如 `ja`）和这个条目对应起来；
3. 在档案里把「语音语言」设为日语，或让角色调用工具时指定语言。

翻译由 AstrBot 中的对话模型完成（可以单独指定一个便宜、快、温度低的模型），和「LLM 口语化清洗」合并为一次调用，
默认 8 秒超时。翻译失败时默认不发语音（外语音色硬念中文效果通常很差），也可以改为念原文。文字消息始终是原文。

## 文本过滤

**正则剥离**会去掉：`*动作*`、`＊动作＊`、各种括号里的内容（`（）`、`()`、`【】`、`[]`）、markdown 标记、代码块和行内代码、
链接、邮箱、HTML 标签、emoji、颜文字。会保留：语气词、拟声词、`～`、`♡`、`♥`、中文标点、数字和英文、引号里的台词。

**正则 + LLM 清洗**在正则之后再让对话模型整理成口语，可以去掉没有标记的旁白（例如「「真厉害！」她得意地笑了」的后半句）。
每次出声多一次模型调用；模型返回明显异常（为空、长度离谱）时退回正则结果。

**发音词典**在最后替换文字，用来纠正名字、英文词和符号的读法（如 `Freezia → 芙蕾齐娅`、`♡ →` 删除）。
全局一张、每个档案一张，同一原文以档案为准；条目可以只对某个语言生效，翻译时也会作为专有名词对照表交给模型。

已知限制：

- `*很*` 这类用星号做强调的写法会被当成动作描写去掉。
- `～`、`♡` 本身不发音，具体读法取决于 TTS 服务的前端处理，请以试听结果为准，需要时用发音词典调整。

## WebUI

在 AstrBot 控制台的插件页面打开「Freezia TTS Speech」：

- **总览**：运行状态与关键指标、运行检查清单（自带语音回复、流式输出、TTS 服务、语言配置等）、语音流水线计数、
  最近 100 条判定记录（显示触发来源、语言和实际朗读的文字，可按结果筛选，重启后清空）
- **发声档案**：新建、编辑、删除档案，设置默认档案；有未保存的修改时会提示
- **会话与全局**：默认 TTS 服务、超时与过期时间、文件服务、调试日志；语言与翻译；全局发音词典；会话档案；静音会话
- **过滤与试听**：粘贴一条回复，逐字查看删掉了什么、判定停在哪一步；可模拟角色调用工具或用户发语音，
  选择语音语言后直接合成试听，显示翻译后实际朗读的文字（带波形，可下载）

侧栏左下角的总开关可以随时暂停或恢复语音回复。

配置保存在 `data/plugin_data/astrbot_plugin_Freezia_TTS_Speech/settings.json`，旧版本的配置会自动补上新字段的默认值。

## 指令

| 指令 | 权限 | 说明 |
|---|---|---|
| `/ftts status` | 所有人 | 查看本会话的档案、TTS 服务、语音语言和会话 ID |
| `/ftts off` | 管理员 | 本会话静音，只发文字 |
| `/ftts on` | 管理员 | 恢复本会话的语音 |
| `/ftts say 文字` | 管理员 | 直接合成一段文字（按本会话档案过滤、清洗 / 翻译），用于测试 |

## 档案字段

| 字段 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | 关闭后使用该档案的会话不发声 |
| 触发概率 | 20% | 满足被动条件时出声的概率 |
| 被动触发上限 | 80 字 | 过滤后超过这个字数不参与概率触发 |
| 冷却 | 30 秒 | 同一会话两次发声的最小间隔 |
| 情绪联动系数 / 情绪符号 | 1.5 倍 / `！ ! ♡ ❤ 哈哈` | 回复里有这些符号时概率乘以系数，1 表示不联动 |
| 发送方式 | 文字 + 语音 | 文字 + 语音 / 仅语音 / 仅文字 |
| 允许私聊 / 群聊 | 开 / 关 | 被动触发的范围 |
| 文本过滤 | 正则剥离 | 正则剥离 / 正则 + LLM 清洗 / 不过滤 |
| TTS 服务 | 跟随全局 | 可让不同档案使用不同音色的服务 |
| 允许角色主动用语音 | 开 | 角色可调用 `freezia_voice_reply` |
| 主动语音最短间隔 | 60 秒 | 同一会话两次主动语音的最小间隔 |
| 语音语言 | 和文字相同 | 选外语时先翻译再用该语言的 TTS 服务合成 |
| 收到语音时用语音回复 | 开 | 用户发来语音消息时这一轮一定念出来 |
| 强制出声短语 | 说给我听、念给我听、用语音说、出声 | 在用户消息里查找 |
| 不出声短语 | 别出声、不要出声、打字就好、别用语音 | 优先于强制出声和角色主动 |
| 发音词典 | 空 | 与全局词典合并，同一原文以档案为准 |

## AstrBot 与协议端不在同一台机器时

TTS 服务返回的是 AstrBot 本机上的音频路径。如果协议端（如 NapCat）在另一个容器或另一台机器上，它读不到这个文件。
请先在 AstrBot 设置 `callback_api_base`，再在 WebUI「会话与全局」里开启「通过 AstrBot 文件服务发送语音」。

## 开发与验证

单元测试（使用 AstrBot 接口替身）：

```bash
py -3 -m unittest discover -s tests -t .
```

真实 AstrBot SDK 离线联调：用 AstrBot 自带的 Python 加载本插件，经真实的插件管理、页面服务、回复装饰阶段、
唤醒与指令分发、工具注册和 `llm_generate` 运行。`ASTRBOT_ROOT` 指向插件 `.qa/` 下的临时目录，
不读取现有配置和数据；模型、TTS 和平台是本地替身，不会联系外部服务或真实用户。

```powershell
& 'D:\AstrBot\backend\python\python.exe' -B tests/smoke_astrbot.py --astrbot-path 'D:\AstrBot\backend\app'
```

脱离 AstrBot 预览 WebUI（使用假的 TTS 和对话模型，只监听 127.0.0.1）：

```bash
py -3 scripts/dev_server.py --port 8765 --demo
```
